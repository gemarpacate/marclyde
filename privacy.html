Privacy Policy

This application is a personal-use application used to access and manage the owner's Google Drive files through rclone.

The application is not offered as a service to the public and is intended solely for personal use by the application owner.

Google User Data

The application accesses Google Drive data only as necessary to transfer, organize, verify, and manage files requested by the application owner.

Data Sharing

Google user data accessed through this application is not sold, shared, or transferred to third parties.

Data Storage

This application does not operate an independent server or database for storing Google user data. File transfers are performed directly between the user's computer and Google Drive through rclone.

Contact

For questions regarding this privacy policy, contact the application owner through the support email shown on the application's Google OAuth consent screen.
